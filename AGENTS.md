# AGENTS.md

## Safety

- Do not publicly share the user's private Gmail address without explicit
  confirmation.
- Keep build artifacts bounded, reuse active caches, and remove only identified,
  unused temporary products.
- Treat Git branches matching `archive/*` as permanent. Deleting, rewriting, or
  repointing one requires one explicit confirmation naming the exact branch and
  whether it is local or remote.

## Working on this repository

This file is for working on Octara itself. Writing apps with Octara is taught by the `octara`
skill (`skills/octara/`, generated by the CLI); read its `SKILL.md` before writing examples or
tests that use the framework, and look names up with `cargo run -q -p octara-cli -- vocab <name>`.

- After changing `crates/octara-cli/skill/body.md` or `docs/start-here.md`, regenerate the skill's
  copy: `cargo run -q -p octara-cli -- skill export skills`. Tests fail while it is stale. The API
  reference is read from the source where the skill is installed; nothing to regenerate.
- A new diagnostic is a new entry in `octara::diagnostics` (cause, doc anchor), reported with
  `&codes::NAME`; tests fail for codes used anywhere but not registered.
- Code blocks in `docs/start-here.md` run as doctests (`cargo test -p octara-cli --doc`); the
  skill ships that page as `references/start-here.md`.
