This OpenType subset is derived from STIX Two Math version 2.13 b171 and is
distributed under the accompanying SIL Open Font License. The original outlines
come from the [STIX Fonts Project release](https://github.com/stipub/stixfonts/releases/tag/v2.13b171).

The subset retains the Latin, Greek and Cyrillic text ranges and mathematical
symbols used by the built-in typesetter. Octara reads the outlines with Swash
and supplies its own spacing and layout.
