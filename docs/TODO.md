# 当前工作清单

这里记录仍需决策或取得证据的工作。通过的实现细节随代码和回归测试维护。

## 第一轮架构验收

- [ ] 桌面文件重命名。决定编辑行离开视口时草稿归属。用同名文件重排、删除、重建三个步骤验证选区、焦点和过期操作。记录一次真实系统输入。
- [ ] 移动面板交接拖动。定义剩余位移、反向接管和取消时刻。以面板消费 12、列表消费 18 的确定性轨迹验证，再在可用的移动宿主验证系统中断。
- [ ] 根据这两个时序列出哪些能力由作者组合、哪些由窗口协调、哪些交给宿主。每个拟公开的入口至少要对应一个用现有公开接口无法正确表达的步骤。[设计样本](design/interaction-scenarios.md)

## 紧随其后的对照

- [ ] 编辑草稿遇到外部模型更新，分别检查相同值、拒绝、替换和已换焦点的迟到提交。比较屏幕候选窗、插入光标、选择和辅助技术使用的坐标。
- [ ] 在两个同时打开的桌面文档上对照撤销的三个入口，核验命令作用域、可用性和实际接收者。
- [ ] 移动端系统返回分别取消和完成，核验页面身份、阅读位置和释放次数；记录使用的宿主和设备。
