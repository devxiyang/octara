# 实现边界与路线图

| 能力 | 仓库目前可以检查什么 | 仍需取得的证据 |
| --- | --- | --- |
| 状态与结构 | Signals、带 key 的集合、挂载和退休；同名对象跨重排、热重载和重建的测试 | 文件重命名中途重排的完整时序，包括原生编辑期间发生删除。[身份测试](../crates/octara/tests/integration/structural_identity.rs) |
| 桌面窗口与绘制 | winit 宿主、CPU 参考绘制、GPU 绘制、检查通道和截图。macOS 有原生编辑、视图适配和跨窗口命令实测 | 各平台的显示回执与原生像素。[宿主](../crates/octara-shell/src/) |
| 输入与语义 | 焦点、快捷键、语义操作、联动触摸位移分配。macOS 实测受控输入与有阶段触控板滚动 | 可编辑文本的 AX 选区与范围坐标。[输入](design/input.md) |
| 组件组合 | 组件库使用公开视图接口实现按钮、表单、弹层、Tabs 和可搜索选择器 | 按桌面、触摸和辅助操作复核哪些行为需要下沉。[组件库](../crates/octara-kit/src/) |
| 移动端 | iOS 27.2 模拟器运行同一面板视图，已核对原生触摸、系统中断、恢复帧、语义树和设备像素 | 中文软键盘、交互式系统返回、真机与 Android 宿主的验收。[iOS 模拟器实测](design/interaction-scenarios.md#ios-模拟器实测) |
| Agent 验证 | 构建收据核对进程，Inspector 读取语义和稳定目标；资料审阅实窗走通诊断、修正与结果回读 | 根据应用实作中反复出现的调用和观察成本决定接口收敛范围。[资料审阅实测](design/interaction-scenarios.md#资料审阅队列) |

## 推进顺序

优先处理复合场景里确实出现的表达和反馈缺口。移动端用模拟器继续检查中文软键盘和系统返回。桌面按平台复核 AX 文字范围。[交互时序](design/interaction-scenarios.md) · [工作清单](TODO.md)
